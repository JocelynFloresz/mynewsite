这里记录了我目前收藏的几款代表性作品，以及它们在特定温湿度下展现出的独特风味。沿着时间线，每一支都承载着一段独处与沉淀的时光。
{{< /lead >}}

{{< timeline >}}

{{< timelineItem icon="fire" header="Drew Estate | Isla del Sol" badge="💰 ¥90 / 支" subheader="尺寸: 127.00 mm × 44 (Corona) · 产地: 🇳🇮 Nicaragua" md=true >}}
{{< figure src="drew1.png" >}}

**风味表现：** ★★☆☆☆ [2/5]

**品鉴档案：**
字面意思为“太阳之岛”的 Isla del Sol，其茄芯混合了尼加拉瓜烟草，并巧妙融入了苏门答腊曼特宁咖啡豆的醇香。在这款日晒版雪茄中，风味浓郁的茄芯被包裹在一片“阳光眷顾”的苏门答腊烟叶中，茄帽部分更以糖霜点缀，使得这些手工卷制的雪茄充满层次丰富的风味，并散发着诱人的香气。
{{< /timelineItem >}}

{{< timelineItem icon="fire" header="Padron | Maduro 3000" badge="💰 ¥150 / 支" subheader="尺寸: 139.70mm × 52 · 产地: 🇳🇮 Nicaragua" md=true >}}
{{< figure src="panton1.png" >}}

**风味表现：** ★★★★☆ [4/5]

**品鉴档案：**
帕德龙系列，此处以 3000 尺寸呈现，采用阳光种植的烟草，均选用尼加拉瓜烟叶制作，经过至少两年半的陈化，此版本全部包裹在马杜罗茄衣之中。
{{< /timelineItem >}}

{{< timelineItem icon="fire" header="Arturo Fuente | Don Carlos #3" badge="💰 ¥200 / 支" subheader="尺寸: 139.70mm × 44 · 产地: 🇩🇴 Dominican Rep." md=true >}}
{{< figure src="ArturoFuente3.png" >}}

**风味表现：** ★★☆☆☆ [2/5]

**品鉴档案：**
阿图罗·富恩特的唐·卡洛斯系列致敬公司创始元老：卡洛斯·富恩特一世。如今，唐·卡洛斯的声望与调配技艺由其子卡洛斯·富恩特二世传承延续，该烟草工坊出品的唐·卡洛斯雪茄是阿图罗·富恩特旗下产量最稀少、最珍罕的雪茄之一。它们以风味与卷制工艺见长，提供绝妙的品吸体验，其特色在于采用陈年多米尼加共和国烟叶与来自喀麦隆的醇美茄衣。
{{< /timelineItem >}}

{{< timelineItem icon="fire" header="Romeo y Julieta | Reserva Real Porto Real" badge="💰 ¥200 / 支" subheader="尺寸: 177.80mm × 36 · 产地: 🇳🇮 Nicaragua" md=true >}}
{{< figure src="RomeoyJulieta.png" >}}

**风味表现：** ★★☆☆☆ [2/5]

**品鉴档案：**
罗密欧与朱丽叶品牌源自古巴，历史可追溯至 1875 年，是雪茄行业最负盛名的品牌之一。其 Reserva Real 系列尤其受到康涅狄格茄衣爱好者的青睐。这款雪茄采用手工精选的厄瓜多尔康涅狄格阴植叶作为茄衣，包裹着尼加拉瓜茄套，以及多米尼加烟草与尼加拉瓜利格罗长芯烟叶的混合配方。Reserva Real 口感醇和柔顺，散发着甜美的木质香气，堪称一日辛劳后犒赏自我的完美选择。
{{< /timelineItem >}}

{{< timelineItem icon="star" header="The Peace (Iron Box)" badge="💰 ¥150 / 盒" subheader="规格: 常规 King Size (铁盒装) · 产地: 🇯🇵 Japan" md=true >}}
{{< figure src="peace.png" >}}

**风味表现：** ★★☆☆☆ [2/5]

**品鉴档案：**
虽然不属于雪茄范畴，但其对烟叶品质的苛求使其完全具备了藏品的资格。采用 100% 精选的顶级弗吉尼亚烟叶，开盒瞬间就能闻到极为浓郁纯正的香草和李子香气。独特的密封铁盒包装完美锁住了水分与香气，燃烧质量极高。
{{< /timelineItem >}}
